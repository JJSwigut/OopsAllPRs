# Google Play Tablet Screenshot Capture

Captured on 2026-07-13 from the current Android app at commit `bfeef3f` plus the privacy-policy change in this branch.

The screenshots are direct, uncomposited emulator captures of a locally signed release build. The release capability omits debug-only developer controls and uses the production application ID and launcher assets.

## 7-inch tablet

- AVD: `OopsPlay7`
- Hardware profile: Nexus 7 (2013), 7.02-inch display
- System image: Android 15 / API 35, Google Play, ARM64
- Native capture size and density: 1200x1920 at 320 dpi, portrait
- Files: `seven-inch-tablet-screenshots/*.png`

## 10-inch tablet

- AVD: `OopsPlay10`
- Hardware profile: Nexus 10, 10.1-inch display
- System image: Android 15 / API 35, Google Play, ARM64
- Native capture size and density: 2560x1600 at 320 dpi, landscape
- Files: `ten-inch-tablet-screenshots/*.png`

For each device, the first screenshot shows the fresh Train surface and the second shows the Profile privacy action after scrolling. Both sizes were visually inspected at original resolution for legibility, clipping, and overlap.
